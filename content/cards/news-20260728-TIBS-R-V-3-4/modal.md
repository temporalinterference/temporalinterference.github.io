# TIBS-R V3.4 – Enhanced Trigger Functions and Protocol Control

With the latest TIBS-R firmware update, we introduce a range of enhancements designed to improve synchronization and simplify protocol development.

In Version 3.4, the synchronization capabilities of TIBS-R have been extended with a programmable digital transistor-transistor logic (TTL) envelope trigger output that can be positioned anywhere within the phase-modulation pattern, which allows external devices to be precisely integrated with TIBS-R. In addition, the analog envelope output has been refined to eliminate timing lags and provide more accurate modulation envelopes.

Protocol programming has also been significantly simplified. Conventional temporal interference stimulation protocols using a specified difference frequency can now be configured with a single convenience function based on phase modulation. Likewise, intermittent theta-burst stimulation protocols can be created with a single command, thereby reducing programming effort and minimizing the potential for configuration errors.

Finally, protocol-level output voltage limits allow users to define voltage caps lower than the 52 V maximum, which improves patient comfort by preventing unnecessary voltage surges if electrode contact quality were to deteriorate during stimulation.

These enhancements make TIBS-R even more flexible and user-friendly for research groups participating in our Early Adopter Program (EAP) and conducting advanced neurostimulation studies.
