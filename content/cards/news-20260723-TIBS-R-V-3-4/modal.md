# TIBS-R V3.4 - Enhanced Trigger Features and Protocol Control

The latest TIBS-R firmware introduces a range of enhancements designed to improve synchronization and simplify protocol development.

Version 3.4 extends the synchronization capabilities of TIBS-R with a programmable digital (TTL) envelope trigger output that can be positioned anywhere within the phase modulation pattern, enabling precise synchronization with external devices. In addition, the analog envelope output has been refined to eliminate timing lag and provide more accurate modulation envelopes.

Protocol programming has also been significantly simplified. Conventional temporal interference stimulation protocols using a specified difference frequency can now be configured with a single convenience function based on phase modulation. Likewise, intermittent theta burst stimulation protocols can be created with a single command, reducing programming effort and minimizing the potential for configuration errors.

Finally, protocol-specific output voltage limits, allowing users to define voltage caps below the 52 V maximum to improve comfort by preventing unnecessary voltage surges if electrode contact quality deteriorates during stimulation.

These enhancements make TIBS-R even more flexible and user-friendly for research groups participating in our [Early Adopter Program](https://temporalinterference.com/#modal-Early-Adopter-Program) and conducting advanced neurostimulation studies.
